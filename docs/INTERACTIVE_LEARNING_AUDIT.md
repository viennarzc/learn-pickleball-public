# Interactive learning opportunities

Reviewed 2026-11-17 against `content/curriculum.js`, the lesson renderer, Court Lab, and the scoring walkthrough. The seven units form the shared curriculum; the entry choices below select or surface parts of it. Suggestions are opportunities, not claims of learner demand or validated effectiveness.

| Learning path or entry | Existing interactions | Opportunities |
| --- | --- | --- |
| Never played / Unit 1: Know the Court | Court Lab, checks, safety scenario, optional practice | Add a hazard-spotting scene with a complete text alternative; compare kitchen bounce and volley cases with feedback. |
| Unit 2: Start a Rally | Serve checks, two-bounce sequence, opening-rally decisions and practice | Add a step-by-step opening-rally ordering exercise that explains each bounce; retain the reading-only route. |
| Unit 3: Keep Score | Score and rotation checks, side-out scenario, separate scoring walkthrough | Practice the transition from server 1 to server 2 with immediate explanatory feedback. **Selected and implemented** on the existing `lose-rally` page; its ID stays the same to preserve recorded page progress. |
| Unit 4: Play the Point | Decision checks and optional drills across groundstrokes, volleys, dinks, transitions and resets | Add branching shot-selection scenarios with contextual feedback and safe, accessible alternatives to physical practice. |
| Unit 5: Play Well With Others | Communication, fair-call and open-play scenarios; first-game rehearsal | Add a dialogue exercise for ambiguous line calls or partner communication, with feedback on sportsmanship and uncertainty. |
| Unit 6: Build a Reliable Game | Multiple tactical decisions, simulations, drills and reflection | Add a sequence linking shot choice to the opponent's next response, while distinguishing coaching options from rules. |
| Unit 7: Deep-Dive Play | Partner-system and safety scenarios, retrieval checks, match reflection | Add a structured match-review planner that turns an observation into one practice goal; avoid requiring personal data. |
| First Game Essentials playlist | Reuses lessons from Units 1–3 and 5, including their checks and rehearsal | Add an optional integrated end-to-end rally review across serve, bounces, score and etiquette; do not add a gate to the playlist. |
| Consistency diagnostic | Five questions direct learners toward a relevant unit | Offer a short, revisitable decision exercise after the recommendation, with clear rationale and no skill rating. |
| Specific answer / Library | Searchable rules and skills, sources and refresher checks | Add optional scenario questions beside rule explanations, linked to the relevant lesson and current source. |

## Selection rationale

The server transition is a common decision inside both the main path and First Game Essentials. The existing page explained server 1 and server 2 transitions but asked for no decision. The new scenario uses the established keyboard-accessible answer controls and existing progress handling, gives corrective feedback, and clarifies that the opening-server exception is outside the scenario. It retains the existing required page ID, so prior completion is not revoked. It is a focused first improvement; the other opportunities remain proposals.
