# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. If private vulnerability reporting is enabled for this repository, use the **Report a vulnerability** option on its GitHub Security page. Otherwise, contact the maintainer privately through the GitHub profile linked from this repository.

Share only the details needed to reproduce the issue. Do not include real learner data, credentials, or other personal information in a report.

## Supported versions

The latest code on `main` is the maintained version. No older release branches are currently documented as supported.
